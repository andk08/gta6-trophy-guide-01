Leonida Trophy Guide — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: official names, descriptions and grades, a guide for every trophy written in our own words that cites its sources, a roadmap to the platinum, the one possibly missable trophy flagged, and a checklist saved in your browser with export and import. No account, no network — the whole guide lives in `app/`.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

To hand the guide in as an entry instead: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts` writes `out/dossier.json` from `app/` and `screenshots/`.
