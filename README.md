An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: official names, descriptions and grades, a cited guide for every trophy written in our own words, a three-stage roadmap to the platinum, missable flags, and a checklist that saves in the browser with export and import. No network needed — serve `app/` with any static server and open `index.html`.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
